# 新手试玩记录表

用于 5–10 位未参与开发的玩家首次试玩。建议每人 20–30 分钟，观察者尽量不提示；卡住超过 2 分钟时记录原话，再给最少提示并继续。

## 开始前

- 使用公开网址和新注册账号，确认验证邮件、登录、忘记密码流程。
- 请玩家边玩边说出自己正在找什么、认为按钮会做什么。
- 未经同意不要记录真实邮箱、密码或其他敏感信息；记录玩家代号即可。
- 每位玩家使用独立测试账号。结束后说明这是测试版本，并收集是否愿意接受后续访谈。

## 试玩任务

1. 注册或登录，找到首页并说出当前最值得做的一件事。
2. 选择一个个人目标，解释还缺什么，以及从哪里开始补足。
3. 找到跨界委托，判断所需物品从哪里获得；确认报酬后完成或说明为何暂不接。
4. 打开界门查看当日市场摘要与跨界背包，完成一次穿越并描述抵达反馈。
5. 找到充值说明、未付款申请取消入口和碎片商店；不要求真实付款。
6. 找到行者名片/好友入口，说出如何添加好友并发送异步留言或祝福。
