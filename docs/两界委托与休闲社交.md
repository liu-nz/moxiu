# 两界委托、收藏故事与休闲社交

本轮沿用首页、界门、行者档案和势力的同行页，不新增独立游戏模式。

- 首页：每日签到 20 灵石，北京时间 05:00 刷新；显示累计和连续签到天数，累计七天获得「七日有约」。签到记录绑定账号，清档与轮回不会再次发奖。
- 界门：两界委托可自选接取，最多追踪两份，锁定报酬并保留 72 小时；放弃不扣资源。灵鸡蛋、灵羊毛、鹿茸可交付现代委托，拥有现代店铺后可接灵米供货。交付需身处目的地且持有物品，每个委托每日一次。已接取进度和最近交付在首页可查看。
- 委托成就：累计十份获得「两界信使」，种田、养殖与采购三类都交付过获得「百业同行」。轮回保留累计交付和来源记录，未交付订单不继承。
- 行者档案：作物、战斗灵兽、牧场灵兽、35 种装备部位与品阶图鉴，显示来源、用途和前往入口。集齐分类获得免费称号；图鉴与已授予称号随轮回保留。
- 首页连续故事：「旧驿来信」四条结局路线；「两界灯火」供货和研究两条路线。追寻线索消耗正常每日奇闻机会，事件间隔三小时，下一章节可能在另一界。分支与结局标记随轮回保留，已完成章节不会再次触发或发奖。
- 同行页：保留 UID 好友申请与接受、解除好友、留言和文字祝福；好友名片增加称号、境界、参考战力和最近活动时间。名片不展示邮箱或后台账号标识。
- 异步照料：每日最多送给五位好友，每位好友一次；对方在 24 小时内领取，每日最多领取一份。优先照料一块生长中的灵田，缩短至多五分钟；没有生长作物时推进一个牧场栏位，最多五分钟且不跨越当前生产周期。未开始种植或养殖时不消耗照料。

新增 12 个免费称号，全部仅用于展示，沿用称号收藏与聊天徽章；不会发放天道碎片或战斗属性。

## 服务器结算

游戏操作仍使用已有 moxiu-game 服务器结算、版本校验与请求回执。签到日、次数与已领取照料保存在私有账号表；客户端不提交奖励值、角色状态或时间。照料发送只能针对已接受好友，重复发送不生成第二份。领取记录与角色保存处于同一数据库事务，丢失响应的重试不会重复缩短等待。

## 验证

`tests/activity.mjs`：跨日、重复领取、重置、牧场累积进度、委托库存与期限、六条故事分支。

`tests/activity.sql`：临时测试账号在回滚事务中验证签到回执、账号记录、好友权限、照料领取、称号授予与客户端访问限制。

`tests/activity.cjs`：浏览器验证签到、照料、委托追踪、图鉴、名片称号，以及桌面和手机布局。

`tests/activity-live.cjs`：仅允许两份专用临时测试账号，验证真实 Auth / RPC / Edge 结算。运行后退出并删除测试账号及其级联数据。
