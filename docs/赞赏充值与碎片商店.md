# 赞赏充值与碎片商店

入口：两个世界的「更多 → 碎片商店」。先登录邮箱账号，访客不能充值。原始赞赏码位于 `assets/images/appreciation-code.png`。

| 赞赏金额 | 天道碎片 |
| --- | ---: |
| ¥1 | 10 |
| ¥5 | 50 |
| ¥10 | 100 |
| ¥25 | 250 |
| ¥50 | 500 |
| ¥100 | 1000 |

玩家选择档位，创建待核对申请，再用微信扫码选择对应金额，付款备注填写页面上的账号 UID。每笔付款只对应一笔申请；网络失败后先刷新记录，已存在的申请可以重新查看赞赏码，不要重复付款。手机可保存图片后在微信识别，也可用另一台设备扫码。没有自动到账回调，玩家申请、截图或 UID 本身都不是付款凭证。

当前收款管理员为唯一原测试账号 UID **10000001**。登录该账号，进入同一页面下方「充值审核」，刷新待处理申请。在微信真实收款记录中核对付款备注 UID、实际收到的金额、微信交易单号。输入实收金额和真实交易单号，勾选核对确认，再发放；没有对应收款则填写原因驳回。审核结果由玩家点击「刷新余额与记录」查看。申请不设到账时限；作者需定期人工核对。每个账号最多同时保留 5 笔待核对申请。

所有商品每账号限购一次，永久拥有。扩容只增加可建造上限，仍须游戏内灵石/人民币支付开垦、扩栏或购房费用。扩容有少量产出收益，不修改修炼速度、突破概率、战斗数值或高阶地产。战斗灵兽原本没有持有上限，本轮不添加持有收费限制，上阵仍限 2 只。称号可展示或取消。

余额、交易流水、永久权益、称号选择保存在 Supabase 的 `moxiu_private.shard_*` 表，独立于可编辑的 `moxiu_test_saves`。导入、清档、轮回不修改它们；删除整个 Auth 账号会级联删除对应记录，不等同于角色清档。页面只读取当前账号的服务器快照，不从本地存档授予权益；服务暂时不可用时保留已有地块和上次确认资料，暂停充值/购买，等待刷新，不自动回退或清空数据。

唯一公开入口 `moxiu_shards(p_action,p_data)` 只授权 authenticated；内部私有函数固定空 search_path，按 `auth.uid()` 判定本人和私有管理员表判定审核权限。客户端不能直接读写钱款表或管理员名单。私有表启用 RLS 且不给客户端表权限，也不设开放访问策略；安全顾问的「RLS Enabled No Policy」信息级提示在这里是有意的默认拒绝。

申请、购买使用 UUID 编号保证重试幂等；商品价格来自服务器目录。钱包行锁串行扣款，余额约束防止透支；权益唯一约束阻止重复购买。审批锁定申请，信用流水与余额更新在同一数据库事务内，每个微信交易单号及入账订单全局唯一。重复确认相同申请与单号不二次发放；错误金额、复用单号和已驳回订单不能入账。管理员权限只通过可信后台授予，Auth metadata 中自报 admin 无效。

部署新项目时先应用 `supabase/migrations/`；管理员绑定是运维操作，不将生成的 Auth UUID 写死进通用迁移。由可信项目管理员核对账号后，在 SQL Editor 按 UID 绑定：

```sql
insert into moxiu_private.shard_admins(user_id)
select user_id from public.moxiu_player_profiles where uid = 10000001
on conflict do nothing;
```

后台核对审计记录（只有项目管理员可执行）：

```sql
select p.uid, o.id, o.amount, o.status, o.receipt, o.created_at, o.reviewed_at,
       reviewer.uid as reviewer_uid
from moxiu_private.shard_orders o
join public.moxiu_player_profiles p using(user_id)
left join public.moxiu_player_profiles reviewer on reviewer.user_id=o.reviewer
order by o.created_at desc;
```

`tests/shards.sql` 在真实数据库使用临时测试账号，覆盖六档换算、权限、审核、防重复凭证、购买幂等、服务器定价、余额隔离、非法请求和可编辑快照隔离，最终全部回滚。`tests/shards.cjs` 用实际 SDK 和模拟 HTTP 响应覆盖充值/审核/购买页面、权益效果、轮回清档、断网和手机布局。测试不产生真实付款或真实账号碎片。

尚未验证真实微信付款端到端到账；上线后的第一笔需作者按上述步骤实际核对。公开邮箱注册仍受现有默认 SMTP 项目成员/发送配额与认证回跳配置限制，见 [云存档运行说明](云存档接入与运行.md)。自动支付回调、退款/冲正、商品转赠不在本轮范围内。
