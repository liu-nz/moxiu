# 玩家交易与论道

2026-10-04。目标：沿用原游戏角色和页面，开放真实玩家之间的物品交易和异步竞技；零预算下不增加常驻游戏服务器。

## 方案与范围

采用卖家挂单、服务器托管货物、买家确认购买的方式。论道使用双方服务器角色，目标玩家无需在线；本轮不实现实时房间、直接赠送、拍卖和竞技资源奖励。

验收标准：货币和货物不重复生成；最后一件货物只能成交一次；双方数据与成交记录一起提交；清档不能重复获得可转卖的初始资金；排行榜只包含真实账号；手机能完成上架、撤回与论道。

## 玩家交易

- 入口：交易行 → 玩家交易。原 NPC 玩法保留在 NPC 委托标签。
- 炼气三层、服务器成长满 30 分钟开放。首版支持背包中的商品、材料和丹药，保持原品质；装备栏、功法和付费碎片不可交易。
- 数量 1–1,000，整数单价 1–10 亿，可选择人民币或灵石。每个挂单只使用一种货币。
- 上架立即从卖家背包移入服务器托管，72 小时有效，可分批购买。沿用原交易行摊位数量，最多 8 单。
- 买家支付全价，卖家到账扣除向上取整的 2% 手续费；上架与撤回不收费。预览与记录显示金额、币种、品质和数量。
- 到期商品不自动删除。卖家可以撤回剩余货物，保留原品质；取回后超重仍保留物品，需要自行整理后穿越。
- 有托管挂单时拒绝清档和升仙。参与玩家交易后，清档不再补发初始人民币，UID、碎片、权益及论道记录继续保留。

## 论道与排行

- 入口：势力 → 排行榜 → 玩家论道。原 NPC 榜保留在折叠区，并明确注明。
- 炼气三层后主动报名，双方均报名才可挑战。服务器根据当前装备、功法、属性和出战灵兽结算，最多 60 回合；显示结果、积分变化与战斗过程。
- 每人每天主动挑战最多 5 次，同一对玩家每天只计分一次，反向挑战也算同一对。每日 UTC+8 05:00 刷新。
- 对手境界相差最多 3 层，积分相差最多 300。胜负使用 Elo，初始 1,000 分，K=24；同一战斗同时更新双方积分。
- 月度积分榜至少完成 3 场当月论道才入榜；月初恢复 1,000 分和当月统计。战力榜使用服务器属性。榜单各显示前 50 名及自己的排名。
- 对战不消耗角色气血、体力，不生成货币、碎片或物品。当前版本没有竞技付费增益或赛季领奖功能。
- 清档不会重置账号当天挑战次数、配对记录或当月积分，防止靠重建角色反复挑战。

## 结算与隐私

共享操作仍走 moxiu-game，先核验登录身份，使用服务器角色和时间。私有数据库表无普通玩家读写权限。两名玩家的角色按固定顺序锁定，检查双方版本和托管余量，原子提交角色、交易或对战记录；失败整体回滚。请求编号保留原重试机制。

公开接口仅返回道号、公开 UID、榜单数值和挂单信息。对手完整角色、登录邮箱与内部账号编号不会进入公开列表。未登录者只能试玩原 NPC 功能。没有真实对手或挂单时显示空状态。
