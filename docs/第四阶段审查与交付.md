# 《墨修》第四阶段：洞府休闲、炼丹联动与自动化

日期：2026-10-02。基于第三阶段 `codex/phase-three-build`，本阶段分支 `codex/phase-four-leisure`。

## 实际完成

| 部分 | 原有问题 | 完成后的行为 |
| --- | --- | --- |
| 灵田续种 | 自动补种全用最后种下的作物，混种被覆盖 | 每块田独立续种计划；可选择休耕，改下茬不影响当前作物；所有已解锁作物均可逐田播种 |
| 收获与补种 | 成熟提醒过的作物可能无法自动收取，自动化不可分开控制 | 独立自动收获、自动补种开关；补种保留灵石，缺钱则等待；空地默认休耕，手动种下才登记该田续种计划 |
| 离线安全 | 无看护的作物刚成熟也可能被偷吃 | 成熟后前12小时安全，之后按实际暴露时间计算风险；有效上阵灵兽或自动灵田研究提供保护 |
| 牧场看护 | 页面显示增产15%，实际未结算 | 看护增产按小数跨周期累计，满一件入账；自动收取可独立暂停，实时显示下批产出时间 |
| 清栏 | 待收产物直接消失 | 清栏前确认，自动收取已有产物；费用不退，未完成周期不结算 |
| 备料目标 | 作物、养殖产物和丹方彼此分散 | 洞府与炼丹共享指定目标，列出材料库存、缺口、种植/养殖/副本来源和境界限制 |
| 炼丹选择 | 固定配方只有点按钮和看结果 | 主材固定，可选稳火、凝药、清毒三种辅材，保留原方；预览成本、成功率、品质药效、失败与反噬，再确认开炉 |
| 炼丹扣料 | 未验证次数、主辅材可能重复计算、反噬记录虚报 | 验证整数1–100炉，先合并同种材料需求；优先消耗普通材料；记录实际损失与逐批结果；每日统计按实际炉数计 |
| 丹药品质 | 丹药全部被背包强制归为普通，无法实现品质药效 | 普通/优质/稀有分行保存；点击某行只服用该行品质；恢复与强化药效实际生效 |
| 修炼丹与保底丹 | 修炼加成可无限叠加，灵元丹日志错误，九转丹吃掉却没效果 | 同类修炼丹替换，强效果保护；时长与强度说明准确；九转丹真正推进突破保底；满体力或满保底不吞药 |
| 自动炼丹 | 研究后没有独立运行流程，道侣代炼错误依赖机器研究 | 研究后手动开启，按选定丹方/辅材每30分钟最多3炉；缺料等待、不换丹方、不积压次数；保留线也约束反噬和道侣代炼 |
| 生产时间 | 离线粗分片导致补种和开炉迟于在线 | 主循环在灵田成熟、牧场产出、炼丹周期切分，先收获再炼丹；长段与不同分片的生产/费用/剩余时间一致 |

种田、养殖、灵兽、道侣、功法、装备、副本、现代经营、跨界贸易、地产、轮回均保留。本轮没有调整各副本曲线、主市场公式、已有作物/丹方的解锁境界或现代产业结构。补齐了炼器未解锁材料名称，并去掉冰莲不存在的背包融化承诺。

## 炼丹具体规则

下表数字为相对原方的变化，成功率最终限制在5%–98%。反噬只在失败后判定，基础条件概率40%，再乘研究与辅材系数。

| 方案 | 额外材料/灵石 | 成功率变化 | 反噬概率系数 | 成功后的品质分布 |
| --- | --- | --- | --- | --- |
| 原方 | 无 | 0 | ×1 | 普通100% |
| 稳火 | 灵鸡蛋1 / 10灵石 | +8个百分点 | ×0.65 | 普通85%、优质15% |
| 凝药 | 黄精草2 / 30灵石；炼气三层解锁 | −8个百分点 | ×1.15 | 普通35%、优质45%、稀有20% |
| 清毒 | 鹿茸1 / 80灵石；金丹初期解锁 | +3个百分点 | ×0.35 | 普通60%、优质30%、稀有10% |

普通/优质/稀有恢复与增益强度为基础的100%/115%/130%，体力取整，修炼丹时长不变。九转保底丹为2/2/3次，最高到下次必成，不把小数作为保底次数。聚气丹仍是可交易商品，不是可服用丹药，品质按既有贸易规则影响售价。主辅材品质不改变炼制参数，低品质材料先使用；库存不足时可能消耗更高品质材料，页面已说明。

同类修炼丹只保留一个效果；更强效果不能被弱丹覆盖，同强度已覆盖完整时长时不消耗。新丹可替换弱效果或延长同强度时长。旧存档中的凝神/灵元效果在下次服用同类丹药时统一替换。

机器每30分钟世界时间检查一次，最多3次尝试，不保证3次成功；更改丹方/辅材会重启周期。暂停时不累计新时间，恢复后继续剩余周期。研究不会自动启动消耗。墨瑶每日职责独立于机器，可未研究先代炼，但使用同一丹方、辅材和资金保留线。两界均可生产，仍受现有离线三天真实时间上限约束。

## 存档和数值影响

仍使用v4存档，新字段由既有迁移补齐。已有混种按当前作物迁移计划；旧空地沿用旧的最后作物，已有明确休耕计划保留。新开局空地休耕。新增自动设置、预算、辅材和最近10批炼丹记录可保存；轮回沿用第三阶段的新开局重置，研究知识保留，机器需重新开启。

自动收获/补种/牧场收取沿用研究解锁后的默认开启行为，可独立关闭。炼丹机默认关闭。保留线只限制对应自动操作，不限制手动消费或其他系统。收益、消耗、品质强度及无限叠药修复会影响已有测试档的成长速度，长期平衡仍待实测。

- 第三阶段47项战斗/配装/轮回检查及手机交互回归通过；第二阶段42项经济/时间检查回归通过。
- 第一阶段26个两界页面、130次多境界渲染与穿越边界回归通过。
