# 第五部分 · Online 阶段（GDD 20.3）—— 进行中

## 一、已定的四项架构决策

| 议题 | 决策 | 理由 |
|---|---|---|
| 联机权威性 | **接受客户端权威** | 托管后端只有客户端 SDK + 行级隔离，没有服务端计算的位置。排行榜与交易行只能做到「防君子不防小人」，界面会如实标注数据来源 |
| 时间基准 | **联机档锁定 1× 倍率** | 兑现 GDD 3.1「界潮全服统一」；倍率会让每个玩家活在不同的时间线上 |
| 首批范围 | **账号 + 云存档** | 其他联机功能的地基 |
| 本地存档 | **首次登录可导入云端** | 已玩进度不白费 |

## 二、已完成：时间基准改造（不依赖云服务，先行落地）

新增 `state.world.mode`，把原来的「倍率开关」升级为两种明确的时间模式：

| 模式 | 世界时钟 | 倍率 | 界潮 |
|---|---|---|---|
| **标准**（默认） | 每帧**对齐真实时间**，而非累加 | 固定 1× | 每日 05:00 全服统一刷新 ✅ |
| **沙盒** | 按倍率推进 | 1× / 10× / 60× | 与全服脱钩 |

实现要点：

- 标准模式下世界时钟**直接取 `Date.now()`**，不累加。这样掉帧、切后台、系统时间被调整都不会让玩家偏离全服窗口。
- 单帧世界时间推进上限 60 秒。否则把系统时间往前拨 30 天，就能靠时钟跳变刷出一大笔收益——这条防线是必须的。
- `advance()` 保留纯累加路径，供离线结算与自动化测试精确控制推进量。

## 三、已完成：存档后端抽象（不依赖云服务，先行落地）

新增 `src/core/storage.js`，把「存档写到哪」和「存档写什么」分开。上层只认 `SaveManager`，
换后端不需要改任何业务代码——云服务激活后在 `PROVIDERS` 里注册 `cloud` 实现即可。

顺手修掉一个真实隐患：**旧版 `save()` 写失败是静默吞掉的**。隐私模式、配额超限这些情况
只会让函数返回 `false` 而无人理会，玩家会在毫无察觉的情况下丢掉全部进度。现在：

- 启动时先自检后端，不可用就直接弹窗告知，而不是等玩了两小时才发现没存下来
- 每次写失败都记账，连续失败会通过提示条上报
- 「人物 → 存档」面板显示后端、最近保存时间、保存状态，并提供**导出 / 导入 / 重置**

导出导入本身也是「首次登录导入本地进度」那条决策的实现基础——先有备份，再谈迁移。

## 四、已完成：启动流程异步化（云存档的硬前提）

原来的 `boot()` 是同步的，`const state = boot()` 直接在模块顶层执行。
同步流程撑不住远程读取，所以先把结构改对——云服务接入时不必再动主流程。

**新的启动顺序**

```
显示启动屏
  → 自检存档后端（隐私模式 / 配额超限立刻可见）
  → 若当前是异步后端：显示「正在读取云端存档…」并 await 云端档
  → decideSaveSource(本地, 云端) 决定用哪一份
  → 绑定 / 启动自动存档 / 结算离线收益 / 渲染 / 启动主循环
  → 隐藏启动屏
```

**存档来源决策**（`save.js` 的 `decideSaveSource`，纯函数、可单测）

| 本地 | 云端 | 结果 |
|---|---|---|
| 无 | 无 | 新建档 |
| 无 | 有 | 用云端 |
| 有 | 无 | 用本地 |
| 有 | 有，且 `savedAt` 相同 | 取云端（本地只是缓存副本） |
| 有 | 有，且 `savedAt` 不同 | **弹窗让玩家裁决**，并说明另一份不会被立刻删除 |

**其余要点**

- 启动失败不再永远卡在启动屏：`boot()` 的 catch 会把错误直接显示在启动屏上，并提示可用 `__moxiu.reset()` 兜底
- `loadAsync()` 在异步后端读取失败时**返回 null 而不是静默降级**，由启动流程决定回落
- `save()` 遇到异步后端时先记账、不阻塞主循环；需要确认结果的场合用 `saveAsync()`
- `registerProvider()` 是给云实现预留的入口，测试里也用它注入假后端来跑通整条路径

## 五、已完成：邮箱认证流程状态机（与 SDK 解耦）

新增 `src/systems/authFlow.js`。账号功能里最容易写错的不是网络调用，而是一堆**时序规则**——
这些规则与网络无关，抽出来就能用假端口完整验证；接云服务时只需实现一个 `authPort`
（对应 `cloud.auth.*`），本文件不用改。

按 Web 端能力实现四种流程：**邮箱+密码登录、邮箱验证码登录、带密码的验证码注册、找回密码**。
（手机短信与微信登录仅限小程序，Web 端不做。）

被固化为代码、并有测试守着的规则：

| 规则 | 为什么 |
|---|---|
| 必须先发码再提交，提交时**不得重新发码** | 重复发码会白白消耗验证码配额，还会让玩家手里的旧码失效 |
| 发码后改了邮箱 → 提交被拦截，提示为当前邮箱重新获取 | 否则会把码发到 A 却拿 B 去验证 |
| 验证码错误时**保留挑战**，可直接重试 | 重发一次码会让玩家之前收到的码作废 |
| 发送失败（含限流）不得声称「已发送」，也不留下可用挑战 | 否则玩家会对着一个永远收不到的码干等 |
| 新用户注册**必须带密码** | 邮箱注册若没设密码，这个账号以后永远无法用密码登录，且要到下次登录才暴露 |
| 登录失败统一提示「账号或密码不正确」 | 不暴露某个邮箱是否已注册 |

## 六、待执行（云服务资源恢复后）

1. 激活云服务并执行 `docs/online-迁移脚本.md`（建 `saves` 表 + 唯一约束 + 4 条 RLS 策略）
2. 用 `registerProvider('cloud', …)` 注册云后端：`isAsync: true` + `readAsync` / `writeAsync`
3. 用 `cloud.auth.*` 实现 `authPort`，接到已完成的 `authFlow` 上
4. 账号界面：登录页、顶部账号状态、同步状态提示、首次登录导入本地进度

**已知限制**：认证只在应用注册的正式 HTTPS 域名上可用，本地预览与 localhost 均不支持——必须发布后才能真机验证登录。发布须沿用同一个 `applicationId`，否则域名变化会让登录因 Origin 不匹配而失败。

## 二、正式版新增的数值结构

### 2.1 属性双轨制

九境界跨度约 168 万倍，属性必须按倍率成长，但百分比词条不能跟着放大，否则会算出「+300% 暴击伤害」。
因此词条分三类计算：

| 类型 | 计算方式 | 代表词条 |
|---|---|---|
| 数值类 | `权重 × 品阶 × 档次 × 境界规模` | 攻击 / 防御 / 气血 / 真元 |
| 百分比类 | `权重 × 品阶 × 档次`（**不乘境界规模**） | 暴击率 / 暴击伤害 / 闪避 / 吸血 / 伤害减免 / 功法威力 / 修炼速度 |
| 小数值类 | `权重 × 品阶` | 速度 |

境界属性倍率（statMult）：炼气 1 → 筑基 6 → 金丹 36 → 元婴 216 → 化神 1296 → 炼虚 7776 → 合体 46656 → 大乘 279936 → 渡劫 1679616。

### 2.2 伤害公式的量级适配

GDD 7.4 原文：`1 - 防御/(防御 + 500 + 等级×50)`。
本作把常数项同步乘以当前境界的属性倍率，公式形态与含义完全保留，只是让它随境界量级一起走。

### 2.3 八副本难度梯度

敌人数值不写死，而是相对「解锁阶段的玩家基础战力」按系数推导：
- 气血 / 防御 ← 玩家在该阶段的基础攻击 × 系数
- 攻击 ← 玩家在该阶段的基础气血 × 系数（约 3.3% ~ 8.8%）
- 速度 ← 玩家基础速度 × 0.85 ~ 1.20

这样八条难度曲线自动跟随境界成长，不会出现后期副本比前期还软的情况。

### 2.4 一轮通关时长

实测（修仙界挂机、速修道途 +25%、无装备加成）：

| 挂机位置 | 通关时长 |
|---|---|
| 修仙界（修炼满速） | **7.8 天** |

## 二、核心循环落地

```
                     ┌──────────── 修仙界（表世界）────────────┐
                     │  挂机修炼涨修为 · 突破境界 · 刷副本掉装备  │
                     │  灵石经济：买功法/强化/买修仙货           │
                     └──────────────────┬─────────────────────┘
                          每日界潮 · 双向穿越 · 带货倒卖（载重限制）
                     ┌──────────────────┴─────────────────────┐
                     │  里世界（现代都市）                      │
                     │  挂机上班赚人民币 · 采购现代货 · 商业升级  │
                     │  人民币经济：买现代货 / 升级商业           │
                     └────────────────────────────────────────┘
```

**关键设计（来自 GDD）**：两界货币互不相通——灵石只能在修仙界花，人民币只能在现代花。
所以玩家必须双向带货才能同时供养两条线，这天然逼出「两界信息差」这个核心身份。

**30 秒循环**：修为自动增长、工资自动结算、界潮倒计时。
**10 分钟循环**：收挂机收益 → 看今日行情 → 决定今天带什么货 → 穿越 → 卖货 → 补货 → 修炼 → 下线。
**深度循环**：刷副本刷装备 → 调功法 → 冲境界 → 开新副本。

**Idle 红线（GDD 21）**：在线收益不得碾压挂机收益，深度玩家收益只比轻度玩家高 30-50%。

## 三、数值设计（全部取自 GDD）

### 3.1 炼气十层修为表（GDD 6.1）

| 层数 | 所需修为 | 累计修为 | 说明 |
|---|---|---|---|
| 炼气 1 层 | 100 | 100 | 开局 |
| 炼气 2 层 | 500 | 600 | |
| 炼气 3 层 | 1,000 | 1,600 | 解锁第一个副本 |
| 炼气 4 层 | 2,000 | 3,600 | |
| 炼气 5 层 | 4,000 | 7,600 | 解锁功法系统 |
| 炼气 6 层 | 8,000 | 15,600 | |
| 炼气 7 层 | 16,000 | 31,600 | |
| 炼气 8 层 | 32,000 | 63,600 | |
| 炼气 9 层 | 50,000 | 113,600 | |
| 炼气 10 层 | 60,000 | 173,600 | 大圆满，可突破筑基 |

> GDD 目标：平均 30-50% 修炼增益下，约 7-14 天通关一轮。MVP 只做炼气~筑基，实测目标是 **约 13-14 小时满速挂机**（炼气约 4.6h + 筑基约 9.1h），配合 10× / 60× 倍率可在 1 小时内走完全程。
>
> 筑基四阶修为需求（GDD 未给表，按同曲线外推）：15 万 / 30 万 / 60 万 / 100 万。

### 3.2 突破机制（GDD 6.2）

- 基础成功率：初期 10% / 中期 20% / 后期 30% / 巅峰 40%
- 保底：**最多失败三次，第四次必成**
- 失败不掉境界，只损失部分修为（本作取当前层已积累修为的 15%）
- 道途「速修」+10% 成功率

### 3.3 界门等级与载重（GDD 3.2，MVP 覆盖 Lv.1-Lv.2）

| 等级 | 跨界载重 | 解锁条件 | 额外效果 |
|---|---|---|---|
| Lv.1 | 10 kg | 初始 | 基础跨界功能 |
| Lv.2 | 18 kg | 筑基期 | 每日穿越次数 +1 |

### 3.4 市场定价（GDD 4.1）

```
实际价格 = 基础价格 × 市场需求系数 × 市场饱和度 × 品质系数 × 事件系数
```

- 需求系数：每日波动，范围 `0.5 ~ 2.0`
- 饱和系数：`max(0.35, 1 ÷ (1 + 当日销售量 ÷ 市场容量))`，每日重置
- 品质系数：普通 ×1 / 优质 ×1.4 / 稀有 ×2.2 / 珍品 ×4 / 绝品 ×8
- 事件系数：世界事件触发时暴涨或暴跌

### 3.5 属性与战斗（GDD 7）

- 五维：HP 气血 / MP 真元 / ATK 攻击 / DEF 防御 / SPD 速度
- 二级属性：暴击率、暴击伤害、命中、闪避、吸血、伤害减免、功法威力加成、修炼速度加成（**不随境界自动提升**）
- 上限：暴击率 75% / 闪避 40% / 吸血 20% / 伤害减免 60% / 修炼速度加成 500%
- 伤害公式：`实际伤害 = 攻击 × 技能倍率 × (1 - 防御/(防御+500+等级×50)) × 暴击系数 × 属性克制系数`

### 3.6 道途（GDD 8）

| 道途 | 核心被动 |
|---|---|
| 战修 | 攻击 +20%，暴击伤害 +30% |
| 法修 | 功法威力 +30%，真元上限 +50% |
| 丹修 | 炼丹成功率 +25%，丹药效果 +20% |
| 器修 | 炼器成功率 +25%，装备强化加成 +15% |
| 商修 | 贸易利润 +30%，店铺客流量 +20% |
| 速修 | 修炼速度 +25%，突破成功率 +10% |

### 3.7 功法与装备（GDD 9）

- 功法：五品阶（黄/玄/地/天/仙）× 四档（下/中/上/极）；四槽位（心法 ×1、招式 ×2、特殊 ×1）
- 装备：七部位（武器/头盔/衣服/鞋子/戒指 ×2/法宝）× 五品阶（凡/灵/宝/仙/神）；强化 +1 ~ +15

### 3.8 副本（GDD 10）

- 八大副本中取前两个：**山贼寨**（炼气 3 层解锁）、**乱葬岗**（炼气 6 层解锁）
- 三难度：普通 / 困难 / 地狱，体力消耗制
- 科技联动（MVP 预留接口）：抗生毒系副本自动解毒、强光手电阴系副本伤害 ×2

### 3.9 世界事件（GDD 14.2）

与界潮同步刷新的全服事件，影响当日行情：丹药热潮 / 灵植丰收 / 现代收藏热 / 灵气异常。

### 3.10 离线收益（GDD 19）

按当前所在世界计算，另一世界 50% 收益；界潮次数累计最多 3 次。
